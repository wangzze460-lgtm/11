小李 —— 桌面语音助手（Windows）

【第一次使用】
1. 把压缩包全部解压（不要在压缩包里直接双击）
2. 双击 JARVIS.exe（Windows 提示“已保护你的电脑”时，点“更多信息”→“仍要运行”）
3. 弹出小窗口时粘贴 API Key，点确定（只需要一次，保存在本机 config.json）
   - 免费：智谱 GLM，https://bigmodel.cn 注册，左侧“API Key”里复制
   - 付费更聪明：DeepSeek（sk- 开头）
   想换 Key：删掉 config.json 再打开
4. 屏幕右下角会出现一个卡通小人，允许麦克风后就能说话

【怎么用】
- 说“小李，打开微信”（喊“贾维斯”也行），它叫你“傅总”
- 只喊“小李”时它会回答“我在”，接下来 10 秒内直接说命令
- 双击小人：打字跟它说
- 按住小人拖动：换位置
- 右键小人：打字 / 隐藏 10 分钟 / 退出
- 说“退出小李”也能关闭

【换成你自己喜欢的形象（比如蜡笔小新）】
在 JARVIS.exe 旁边新建文件夹 avatar，放进 PNG 图片（透明背景最好）：
  idle.png   平时的样子（必须有）
  talk.png   说话时（可选；再放一张 talk2.png 会两张交替，像在动嘴）
  listen.png 在听你说话时（可选）
  think.png  思考时（可选）
重新打开就会用你的图片。

【它会做的事】
打开软件（微信、QQ、浏览器、剪映、Steam……桌面和开始菜单里有的都行，卸载程序永远不会打开）
打开网站、在百度/B站/抖音/淘宝/YouTube 搜索
整理桌面（能撤销）、找文件、新建文档、打字、快捷键、调音量、截图、锁屏、报时、聊天

【说明】
- 语音识别完全离线，只有转成文字的命令会发给 AI
- 免费模型很忙时会自动重试并换备用免费模型
- 不会删除文件、不会关机
- 运行记录在 jarvis.log
