J.A.R.V.I.S. 本地语音助手（Windows）

【第一次使用】
1. 把压缩包全部解压（不要在压缩包里直接双击）
2. 双击 JARVIS.exe（Windows 提示“已保护你的电脑”时，点“更多信息”→“仍要运行”）
3. 第一次会让你粘贴 API Key，回车后自动保存：
   - 免费：智谱 GLM，去 https://bigmodel.cn 注册，在“API Keys”里创建
   - 付费更聪明：DeepSeek，https://platform.deepseek.com/api_keys （sk- 开头，充几块钱能用很久）
   想换 Key：删掉 config.json 再打开
4. 允许麦克风，听到“我在”就可以说话了

【怎么用】
- 说“贾维斯”，它回答“我在，先生”，然后直接说要做的事
- 也可以一口气说：“贾维斯，打开微信”
- 唤醒后 10 秒内可以连续下命令，不用每次都喊名字
- 黑色窗口里也能直接打字回车
- 说“退出贾维斯”关闭

【它会做的事】
打开软件（微信、QQ、浏览器、剪映、Steam……桌面和开始菜单里有的都行）
打开网站、在百度/B站/抖音/淘宝/YouTube 搜索
看桌面有什么、把桌面文件按 图片/视频/文档/表格/压缩包 归类（说“撤销整理”可还原）
找文件、打开文件夹
在桌面新建文档写文案/清单
在光标处打字、按快捷键（比如“保存”= ctrl+s，“回到桌面”= win+d）
调音量、静音、暂停/下一首
截图到桌面、锁屏、报时，以及正常聊天问问题

【说明】
- 语音识别完全离线（Vosk），说话内容只有转成文字后的命令会发给 DeepSeek
- 语音播报用微软 edge-tts（需联网），连不上会自动换成系统自带语音
- 不会删除文件、不会关机；整理桌面只移动文件，并且能撤销
- 想换声音：编辑 config.json 里的 voice，例如 zh-CN-YunyangNeural（男声播音）、zh-CN-XiaoxiaoNeural（女声）
- 唤醒词识别不准时，把麦克风离近一点，或在 config.json 的 wake_words 里加拼音，例如 "jia wei shi"
